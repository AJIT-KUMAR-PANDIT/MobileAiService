Initial Setup

The MobileAiService IoT system uses the iotsystemslabs.local domain for local development and testing.

// Base URL configuration
export const IOT_BASE_URL = 'http://iotsystemslabs.local:3001';

Configuration

Configure your IoT devices through the following endpoints:

  • Device Registration: /api/devices/register
  • Device Status: /api/devices/status
  • Device Control: /api/devices/control

Supported Devices

Lighting

Control smart lights, lamps, and LED strips

Climate

Manage thermostats and AC units

Security

Access cameras and door locks

Voice Commands

Example voice commands for Luna AI:

  • "Turn on the lights in the living room"
  • "Set bedroom temperature to 72 degrees"
  • "Lock the front door"

Troubleshooting

Device Connection Issues

Ensure your device is connected to the same network as the IoT system.

Voice Recognition

Check microphone permissions and wake word sensitivity settings.
